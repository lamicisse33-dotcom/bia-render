# BIA — consignes du propriétaire

BIA est actuellement une application web. `https://app.khalam.app` est la version de référence.
Pour toute modification produit dont la publication est demandée ou autorisée, publier aussi sur cette application web et vérifier la version effectivement servie. Une publication iPhone seule ne termine pas le travail.

Lire `AVANT-DE-DIRE-QUE-C-EST-BON.md` avant de déclarer un problème de voix, d'écoute ou de micro résolu. Distinguer les tests, la publication, la génération audio et la lecture effectivement mesurée dans le navigateur.

Pour les sujets couverts par les devoirs mémorisés dans Supabase, privilégier un dialogue fondé sur leurs formulations exactes : une réplique adaptée au contexte, au maximum une question, puis attendre la réponse. Ne pas réciter tout le devoir, ouvrir automatiquement l'apprentissage ou inventer une reformulation wolof à la place d'une formulation apprise.
